TEMseg is a desktop application we built that automates nanoparticle analysis from electron microscopy images. The core challenge was running two large vision models (a 30M parameter detector and a 100M parameter segmentation model) in a pipeline that feels interactive. We achieved single seconds refinement operations by caching model embeddings and using ONNX runtime optimization. The system extracts per-particle morphology statistics calibrated to physical units and fits size distributions against reference models. wet ships as a self-contained native app with no dependencies. All this ensures researchers get results in minutes instead of the hours of manual tracing they do today.

I think I’m a strong fit because my background sits across both machine learning and systems engineering. Most of my work has involved deploying machine-learning models, specifically computer-vision systems and building lower-level software in C/C++, which gives me experience at both ends of the stack: model behavior during inference and the underlying system-level observability around it.

That combination makes me especially interested in directions like building “inspector agents”: monitoring systems that combine granular telemetry (RSS and memory allocation, CPU load, process activity) with model-side signals such as attention patterns or output distributions. The goal would be to answer operational questions in real time: is this model actively training or serving inference, is its behavior consistent with expected deployment, and are there early indicators of abnormal or unauthorized activity?
